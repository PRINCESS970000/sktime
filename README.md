`sktime` is an open-source library providing a unified interface for time series tasks including forecasting, classification, and clustering. We are currently focused on enhancing our **Deep Learning capabilities** by migrating specialized models to **PyTorch**.

## ⏳ Installation (2026 Standards)

Optimized for modern architectures (including Apple Silicon and Windows 11).

- **OS**: Linux · macOS (M1/M2/M3 optimized) · Windows 10/11
- **Python**: 3.10, 3.11, 3.12, 3.13, and **3.14 (Stable)**
- **Architecture**: 64-bit

```bash
# Standard installation
pip install sktime

# Full installation (including Deep Learning & Networks)
